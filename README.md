## Just image Transformer (JiT) for Pixel-space Diffusion

This is the solution of Just JiT Team for NTIRE Workshop and Challenges @ CVPR 2026 The Second Challenge on Day and Night Raindrop Removal for Dual-Focused Images

### Train
To repeat the train process, change the paths and run the following command:
```bash
sh train_jit13.sh
```
```bash
sh train_jit22.sh
```

### Inference
To repeat the infer process, change the paths and run the following command:
```bash
python infer_aug_ensemble.py
```
